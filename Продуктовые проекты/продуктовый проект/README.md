# Прототип корзины

Версия 1.0 для модератора, 24 ноября 2026 года.

- [Вариант A](A.html) показывает способы получения и итоговые суммы при оформлении.
- [Вариант B](B.html) показывает тот же блок и в корзине. При переходе к оформлению выбранный способ сохраняется.

Обе версии используют одни демонстрационные товары, цены, город и способы получения. На старте ни один способ не выбран. При смене способа итог пересчитывается. В прототипе нет оплаты, отправки заказов и полей для персональных данных.

## Как открыть

Распакуйте весь архив, чтобы оба HTML-файла, `cart.js`, `styles.css` и папка `assets` сохранили расположение. Для запуска с диска откройте `A.html` или `B.html` в обычном браузере. Для новой сессии перезагрузите назначенный вариант.

Для локального HTTP запустите команду из корня кейса на компьютере, где будете показывать прототип:

```bash
python -m http.server 8123 --bind 127.0.0.1 --directory stage2/prototype
```

В браузере на том же компьютере откройте `http://127.0.0.1:8123/A.html` или `http://127.0.0.1:8123/B.html`. Выберите назначенную версию до начала сессии и покажите участнику только её. Проверку поведения и ограничения среды см. в [протоколе QA](QA.md).
