При базовых допущениях нужен рост продлений на 0,39 п.п. | [Кейс](Фуди%20-%20перенос%20доставки/Окупится%20ли%20перенос%20доставки.pdf) · [Excel](Фуди%20-%20перенос%20доставки/Расчёт%20окупаемости%20переноса.xlsx) |
