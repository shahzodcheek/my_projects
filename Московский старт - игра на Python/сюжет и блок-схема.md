# Московский старт — сюжет и блок-схема

Игра начинается с бюджета 50 000₽ и оплаты хостела (−5 000₽). Далее игрок выбирает стратегию: работа, учёба или бизнес. Каждый выбор ведёт к новым развилкам и одной из шести концовок.

## Краткое описание веток
- **Работа**: курьер в сервисе доставки → согласиться на серую схему (Тюрьма) или отказаться и вырасти в карьере (Семья).
- **Учёба**: студент IT → варианты удержаться на плаву:
  - академ + работа → переход к ветке Работа;
  - кредит на учёбу → долг (Долговое рабство);
  - подработка по специальности → стажёр (Специалист) или бросить учёбу и открыть бизнес (переход к ветке Бизнес).
- **Бизнес**: выбор направления:
  - интернет-магазин → взять товар без документов (Тюрьма) или работать легально (Бизнесмен);
  - кофейня на кредит → бизнес не взлетает (Возвращение домой).

## Текстовая блок-схема
```
Старт (50 000₽ → −5 000₽ хостел)
├─ Работа
│  └─ Серые схемы? да → Тюрьма
│                    нет → Семья
├─ Учёба
│  ├─ Академ + работа → (Ветка Работа)
│  ├─ Кредит → Долговое рабство
│  └─ Подработка
│     ├─ Стажёр → Специалист
│     └─ Бросить и бизнес → (Ветка Бизнес)
└─ Бизнес
   ├─ Интернет-магазин
   │  ├─ Без документов? да → Тюрьма
   │  └─ нет → Бизнесмен
   └─ Кофейня (кредит) → Возвращение домой
```

## Концовки
- Специалист — закончить учёбу и стать профи в IT.
- Бизнесмен — вырастить легальный проект в Москве.
- Семья — отказаться от серых схем и обрести баланс.
- Тюрьма (15 лет) — рискованные сделки в работе или бизнесе.
- Возвращение домой — кофейня в кредит не окупилась.
- Долговое рабство — кредит на учёбу затянул.
