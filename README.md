## Gedling - контроль исполнения бюджета

Провёл план-факт анализ бюджета трёх муниципальных спортивных центров за 2025/26 финансовый год на открытых данных Gedling Borough Council. В Excel сопоставил исходный бюджет, уточнённый план и фактические расходы.

Чистые расходы оказались на £317 252 (30,0%) ниже уточнённого плана. По итогам анализа предложил сохранить базовый бюджет на персонал до проверки вакансий, фактически отработанных часов и плана найма.
